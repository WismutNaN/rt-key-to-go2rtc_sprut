# Документация проекта RT Key → go2rtc для SprutHub

Проект превращает облачные камеры «Ростелеком Ключ» с временными токенами в постоянные RTSP-потоки с авторизацией. Целевой вариант разворачивается через Docker Compose на Linux-сервере в локальной сети и выдаёт готовые ссылки для добавления всех найденных камер в SprutHub.

Проект предназначен для одного владельца домашней инфраструктуры. Он не является официальной интеграцией Ростелекома и не может автоматически восстановить истёкший основной Bearer Token.

## Быстрый старт

```text
git clone <адрес-репозитория>
cd rt-key-to-go2rtc_sprut
./install.sh
```

Установщик скрыто запрашивает Bearer Token, генерирует пароли, запускает `docker compose` и выводит для каждой камеры постоянную ссылку вида:

```text
==========================================
Данные камер для SprutHub
==========================================
Логин:  spruthub
Пароль: <случайный пароль>

Подъезд [camera-uid]:
rtsp://spruthub:<пароль>@192.168.1.50:8554/podezd
==========================================
```

## Текущий статус

Docker-вариант реализован полностью. На машине разработки выполнены только офлайн-тесты Python и статические проверки; Docker по условию владельца не запускался. Реальный Bearer Token, потоки, звук и доступ из SprutHub проверяются по чек-листу на целевом Linux-сервере.
