# Модуль: Контроллер обновлений

**Ответственность**: оркестрирует восстановление, обнаружение камер, PATCH и планирование следующего refresh.
**Расположение**: `src/rtkey_gateway/application/sync_video.py`

## Публичный интерфейс

| Символ | Тип | Описание |
|---|---|---|
| `SynchronizeVideoFeeds` | class | Главный синхронный сервисный цикл |
| `restore_last_good()` | метод | Восстанавливает только неистёкшие сохранённые sources |
| `refresh_once()` | метод | Выполняет один полный цикл с изоляцией камер |
| `run()` | метод | Работает до SIGTERM/SIGINT и завершает текущую атомарную запись |

## Зависимости

| Модуль | Что использует |
|---|---|
| `application.ports` | `VideoCatalogPort`, `MediaGatewayPort`, `MediaProbePort`, `VideoStateRepository`, `Clock` |
| `domain.video` | Камеры, bindings и naming policy |
| `domain.media` | Audio policy и media profiles |

## Инварианты

- Первый успешный fetch происходит вскоре после старта, независимо от LKG.
- LKG применяется только если его `exp` позже текущего времени с защитным запасом.
- Ошибка одной камеры не блокирует обработку следующей.
- Новый source становится LKG только после RTSP/upstream probe; при отказе восстанавливаются прежние upstream и media profile.
- Истёкший или истекающий менее чем через минуту token не применяется; остальные срочные повторы ограничены `retry_min`.
- При auth error retry остаётся редким и health явно сообщает о необходимости заменить Bearer.
- Между refresh controller раз в `RUNTIME_CHECK_SECONDS` сверяет имена go2rtc и восстанавливает пропавшие runtime-streams из действующего LKG.
- SIGTERM не оставляет частично записанный state.
- Use case не импортирует `requests`, конкретный go2rtc client или JSON repository.

## Намеренно НЕ обрабатывает

- Интерактивный ввод и вывод ссылок.
- Автоматическую смену Bearer Token.
- Реальное декодирование или транскодирование media.

## Заметки для агента

> JWT `exp` переводится в относительную задержку после каждого fetch. Ожидание выполняется через `Event.wait`, поэтому SIGTERM/SIGINT немедленно прерывает сон. Wall-clock внедрён для детерминированных тестов.
