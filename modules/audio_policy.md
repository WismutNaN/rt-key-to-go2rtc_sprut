# Модуль: Политика аудио

**Ответственность**: независимо от Ростелеком API выбирает media profile для передачи или транскодирования аудиодорожки каждой камеры.
**Расположение**: `src/rtkey_gateway/domain/media.py`

## Публичный интерфейс

| Символ | Тип | Описание |
|---|---|---|
| `AudioMode` | enum | `copy`, `aac`, `pcma`, `pcmu`, `none` |
| `MediaProfile` | dataclass | Неизменяемые `video_mode=copy` и выбранный `audio_mode` |
| `AudioPolicy` | class | Читает глобальный режим и необязательные overrides по UID |
| `profile_for()` | метод | Возвращает эффективный media profile конкретной камеры |

## Зависимости

| Модуль | Что использует |
|---|---|
| `domain.video` | `CameraId` для per-camera override |

## Инварианты

- Видео в v1 всегда использует `copy` независимо от аудиорежима.
- Значение по умолчанию — `copy`.
- Неизвестный режим завершает проверку конфигурации с понятной ошибкой до PATCH.
- Per-camera override имеет приоритет над глобальным значением.
- Изменение audio policy не меняет публичный RTSP URL или mapping UID → name.

## Намеренно НЕ обрабатывает

- Автоматическое определение совместимости SprutHub.
- Двустороннее аудио и backchannel.
- Транскодирование видео.
- Анализ качества и синхронизации аудио.

## Заметки для агента

> Конфигурация v1 может начинаться с одного `AUDIO_MODE=copy`, но внутренний интерфейс сразу должен принимать mapping `uid → AudioMode`. Это позволит позднее добавить файл overrides или автоматический probe без изменения API-клиента, state schema и построителя URL. Режим `none` нужен как безопасный fallback для камер с повреждённой аудиодорожкой.
