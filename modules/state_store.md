# Модуль: Хранилище состояния

**Ответственность**: надёжно хранит стабильный реестр камер, проверенные last-known-good upstream/media profile и диагностический статус.
**Расположение**: `src/rtkey_gateway/infrastructure/json_state.py`

## Публичный интерфейс

| Символ | Тип | Описание |
|---|---|---|
| `GatewayState` | dataclass | Версия схемы, bindings и метаданные последнего цикла |
| `JsonVideoStateRepository` | class | Валидация, чтение и атомарная запись JSON |
| `load()` | метод | Читает основной файл или валидный backup |
| `save()` | метод | Пишет temp, fsync, backup и atomic replace |
| `sanitized()` | метод | Возвращает состояние без sources и секретов |

## Зависимости

| Модуль | Что использует |
|---|---|
| `application.ports` | Реализует `VideoStateRepository` |
| `domain.video` | Сериализует/восстанавливает camera bindings |
| Python filesystem API | `fsync`, права и atomic replace |

## Инварианты

- Каждая запись содержит `schema_version`.
- Файл и backup имеют права `0600`, каталог не доступен посторонним на запись.
- Неизвестная версия схемы не перезаписывается.
- Повреждённый основной файл не уничтожает валидный backup.
- Status-представление не содержит Bearer, streamer token, password или full source.

## Намеренно НЕ обрабатывает

- Шифрование volume at rest.
- Одновременную запись несколькими controller.
- Облачную синхронизацию состояния.

## Заметки для агента

> Compose должен запускать ровно одну replica controller. Временный source считается секретом. Adapter владеет JSON-схемой; доменные классы не знают о JSON. При миграции сначала сохранить исходный файл отдельной резервной копией и лишь затем записывать новую версию.
