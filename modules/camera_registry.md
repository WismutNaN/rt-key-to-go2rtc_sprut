# Модуль: Реестр камер

**Ответственность**: сохраняет стабильное и уникальное публичное имя каждой камеры независимо от порядка API.
**Расположение**: `src/rtkey_gateway/domain/video.py`

## Публичный интерфейс

| Символ | Тип | Описание |
|---|---|---|
| `CameraId` | value object | Непустой внешний идентификатор камеры без знания формата API |
| `CameraFeed` | entity snapshot | CameraId, title, секретный upstream URL и `expires_at` |
| `StreamName` | value object | Валидное постоянное имя RTSP stream |
| `CameraBinding` | entity | CameraId, StreamName, title и last-known-good metadata |
| `StreamNamingPolicy.reconcile()` | метод | Объединяет сохранённый реестр с текущим списком API |
| `StreamNamingPolicy.slug_from_title()` | метод | Транслитерирует и нормализует title Ростелекома |

## Зависимости

| Модуль | Что использует |
|---|---|
| Только Python stdlib | Домен не зависит от adapter/application слоёв |

## Инварианты

- Известный UID сохраняет выданный slug при перестановке камер и изменении title.
- Slug уникален без учёта регистра.
- Разрешены ASCII-буквы, цифры, `_` и `-`; имя не начинается с точки или дефиса.
- Исчезнувшее имя резервируется и не назначается новой камере автоматически.
- Изменение title не меняет stream name.
- Домен не содержит `streamerToken`, `streamerUrl`, camelCase/snake_case и endpoint Ростелекома.

## Намеренно НЕ обрабатывает

- Доступность upstream и срок токена.
- Удаление истории исчезнувших камер без явной команды.

## Заметки для агента

> Базовое имя строится из `title`: lower-case ASCII, транслитерация кириллицы, разделитель `_`, без повторных разделителей. Например, `Подъезд № 1` → `podezd_1`. Если title пустой, результат пуст или имя занято, используется `camera_<первые 8 символов UID>` либо suffix `_<uid8>`. Для первой установки входной список сортируется по UID, а сохранённое имя не меняется при последующем изменении title.
